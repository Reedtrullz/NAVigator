# 03 - Arbeidsmarkedstjenester

NAV tilbyr et bredt spekter av tjenester for jobbsøkere og arbeidssøkere.

---

## Komme i jobb - Inngangsportalen
- **URL**: https://www.nav.no/komme-i-jobb
- **Oppdatert**: 14.08.2026
- **Formål**: Samlet inngang for alle arbeidsmarkedstjenester
- **Adgang**: Alle kan registrere seg som jobbsøker; NAV vurderer behov under arbeidsmiljøloven §14a

## Registrering som jobbsøker
- **URL**: https://www.nav.no/registrer-arbeidssoker
- **Formål**: Registrering for å få jobbsøkerrettigheter og delta i formidling
- **Hvem**: Alle som er klare til å søke jobb

## Jobbsøking og formidling

### Arbeidsplassen.no
- **URL**: https://arbeidsplassen.nav.no
- **Formål**: NAVs offisielle jobbportal - søk stillinger, lag CV, kontakt arbeidsgivere
- **Engelsk**: Tilgjengelig på engelsk via arbeidsplassen.nav.no/en/
- **Funksjoner**: Jobbsøking, CV-deling (med samtykke), relevante stillingsvarsler

### Finne jobb
- **URL**: https://www.nav.no/soker-jobb
- **Formål**: Veiledning for jobbsøking

### Min CV
- **URL**: https://www.nav.no/min-cv
- **Formål**: Digital CV som kan deles med relevante arbeidsgivere

---

## Veiledning og oppfølging

### Behov for oppfølging
- **URL**: https://www.nav.no/behov-for-oppfolging
- **Formål**: Vurdering av hva slags oppfølging du trenger

### Arbeidsrettet oppfølging
- **URL**: https://www.nav.no/arbeidsrettet-oppfolging
- **Formål**: Jobbspesifikk veiledning og oppfølging
- **Tilgang**: Kan søkes uten registrering som jobbsøker

### Aktivitetsplan
- **URL**: https://www.nav.no/aktivitetsplan
- **Formål**: Digital plan for aktiviteter og mål i samarbeid med NAV-veileder

### Veiledning og råd
- **URL**: https://www.nav.no/opplysning-rad-veiledning
- **Formål**: Generell veiledning (lovbestemt rettighet)
- **Alternativ**: https://www.nav.no/snakke-med-nav

### Jobbklubb
- **URL**: https://www.nav.no/jobbklubb
- **Formål**: Kurs i jobbsøking og arbeidsmarkedet

### Digitalt jobbsøkercurs
- **URL**: https://www.nav.no/digitalt-jobbsokerkurs
- **Formål**: Nettkurs for jobbsøkere

---

## Arbeidstrening og avklaring

### Arbeidstrening
- **URL**: https://www.nav.no/arbeidstrening
- **Formål**: Arbeidserfaring med tilpassede oppgaver, NAV+arbeidsgiverkontakt

### Avklaring
- **URL**: https://www.nav.no/avklaring
- **Formål**: Kartlegge arbeidsevne og muligheter

### Arbeid med støtte
- **URL**: https://www.nav.no/arbeid-med-stotte
- **Formål**: Oppfølging i ordinært arbeid

### Oppfølgingstiltak
- **URL**: https://www.nav.no/oppfolging
- **Formål**: Generelt oppfølgingstiltak

### Friskmelding til arbeidsformidling
- **URL**: https://www.nav.no/friskmelding-arbeidsformidling
- **Formål**: Opptil 12 uker sykepenger mens du søker ny jobb etter utmattelse fra tidligere arbeidsplass

- **URL**: https://www.nav.no/arbeidsrettet-veiledningstjeneste

### Psykiske helseproblemer

- **Formål**: Informasjon og tilbud for personer med psykiske helseproblemer
