# 10 - Internasjonale tjenester

NAV forvalter regler for arbeid og opphold i utlandet, EØS-samarbeid og eksport av ytelser.

---

## Arbeid og opphold i utlandet
- **URL**: https://www.nav.no/arbeid-og-opphold-i-utlandet
- **Formål**: Folketrygdmedlemskap, trygdeavtaler, eksport av ytelser

## Jobb i Norge (for utlendinger)
- **URL**: https://www.nav.no/jobb-i-norge
- **Formål**: Informasjon og veiledning for personer som skal jobbe i Norge

## Arbeid og opphold i Norge (detaljert)
- **URL**: https://www.nav.no/arbeid-og-opphold-i-norge/...
- **Formål**: Regler for arbeid, opphold og trygdevedlemskap

---

## EØS-regler

### EØS-arbeid
- **URL**: https://www.nav.no/jobbe-i-eos
- **Formål**: EØS/Sveits-regler, A1-sertifikat
- **Hovedregel**: Arbeidstakere i Norge er obligatorisk folketrygdmedlem fra første dag (unntak: utsendte med A1)

### EØS-utlandet
- **URL**: https://www.nav.no/arbeidsledig-i-eu-eos
- **Formål**: Eksport av arbeidsledighetstrygd innen EØS

### EØS-generell
- **URL**: https://www.nav.no/eos
- **Formål**: EØS-regler, medlemskap, utsendte arbeidstakere

### Pensjon i utlandet
- **URL**: https://www.nav.no/pensjon-i-utlandet
- **Formål**: Eksport av pensjonsytelser

---

## Nordisk samarbeid
- Nordisk trygdekoordinering skjer innenfor EØS-rammen
- Særskilte regler for nordiske borgere

---

## Medlemskap i folketrygden

### Søknad om medlemskap
- **URL**: https://www.nav.no/sok-medlemskap-i-folketrygden
- **Formål**: Søknad om medlemskapsvedtak

### Generelt om medlemskap
- **URL**: https://www.nav.no/medlemskap
- **Formål**: Bosted/arbeidsmedlemskap, 12-månedersregel, frivillig medlemskap, EØS/trygdeavtaler

---

## Flyktninger og innvandrere

### Introduksjonsprogram
- **URL**: https://www.nyinorge.no/introduksjonsprogram/
- **Ansvar**: Kommunal oppgave (NAV kan samordne)
- **Innhold**: Norskkurs, samfunnskunnskap, arbeidsmarkedstiltak

### Introduksjonsstønad
- **URL**: https://www.nav.no/introduksjonsstonad
- **Formål**: Kommunal ytelse under introduksjonsprogrammet

### Arbeidsrettet oppfølging
- **URL**: https://www.nav.no/arbeidsrettet-oppfolging
- **Formål**: Sysselsettingsrettet oppfølging for innvandrere

### NAV Ukraina
- **URL**: https://www.nav.no/ukraina
- **Formål**: Kollektiv vernede kan arbeide direkte eller tilbys introduksjonsprogram inkl. norsk/arbeidslivskunnskap
