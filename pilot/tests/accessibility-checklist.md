# Tilgjengelighetskontroll på eksakt kandidat

WCAG 2.2 AA er testmål, ikke en juridisk samsvarserklæring. Registrer HTML-SHA, enhet/nettleser, kontrollør og dato per faktisk prøve.

| Kontroll | Agentprøve 08.10.2026 | Gjenstående menneskelig kontroll |
|---|---|---|
| 320 px reflow og lange primærsvar | Kontrollert uten horisontal overflow; radiotekst brytes | Flere lokale enheter og stor tekst |
| 390/768/1280 px | Fersk dokumentmåling føres i browser-evidence.json | Faktisk enhet ved behov |
| Tastatur, native radio/checkbox/details | Hovedoppgave og fokus etter eksplisitt viderehandling kontrolleres | Full Tab-/Shift-Tab-rute på brukerens nettleser |
| Fokus etter notatfravalg | Feil funnet og rettet; gjenopprettes på samme kontroll | Skjermleser ved endring av innhold |
| Én kort statusregion | Kun ett role=status; lange kort/notater uten live-region | VoiceOver faktisk opplesing |
| Manglende JavaScript | Faktisk prøvd med script deaktivert og ny sideinnlasting; statisk hjelp tilgjengelig | Brukerens nettleser |
| Redusert bevegelse | Ingen påtvunget scrolling eller dekorativ animasjon; CSS-regel finnes | OS-innstilling og brukeropplevelse |
| 200/400 % zoom | NOT_RUN; smal viewport er ikke faktisk zoomtest | Faktisk zoom, fokus og lesbarhet |
| Tekst-/kontrollkontrast | Beregn faktiske faste fargepar; logg resultat | Alle tilstander og valgt/høy kontrast |
| Utskrift | Faktisk browser-PDF og valgt innhold kontrollert | Papirutskrift og printerinnstillinger |

Prøv oppgaven med «Vet ikke» og «Vil ikke oppgi», bare ett svar, ingen tekst, endret svar, ugyldig fil og signalutløst hjelp. Kritiske stopp eller misforståelser skal rettes før videre utprøving. Ikke la attributtkontroll erstatte faktisk bruk av hjelpemiddel.
