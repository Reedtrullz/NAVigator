# 09 - Hjelpemidler og tilrettelegging

NAV forvalter hjelpemidler og tilretteleggingstiltak for personer med varig nedsatt funksjonsevne.

---

## Hovedportal for hjelpemidler
- **URL**: https://www.nav.no/hjelpemidler
- **Formål**: Samlet inngang for alle hjelpemidler og tilrettelegging

## Veiledning om hjelpemidler
- **URL**: https://www.nav.no/hjelpemidler-og-tilrettelegging
- **Formål**: Generell veiledning og informasjon

---

## Kategorier hjelpemidler

### Hørsel
- **URL**: https://www.nav.no/har-nedsatt-horsel
- **Hjelpemidler**: Høreapparater, tinnitusbehandling, telespole, hørselssløyfer

### Syn
- **URL**: https://www.nav.no/syn
- **Hjelpemidler**: Forstørrelse, lesemaskiner, spesialbelysning

### Tale og språk
- **URL**: https://www.nav.no/tale-sprak
- **Hjelpemidler**: Kommunikasjonsenheter, talemaskiner

### Kognitiv
- **URL**: https://www.nav.no/huske-planlegge
- **Hjelpemidler**: Kognitive programvare, påminnelsesutstyr

### Mobilitet
- **URL**: https://www.nav.no/bevegelse
- **Hjelpemidler**: Rullestoler, krykker, gangere, stårammer, barnevogner

### Lesing og skriving
- **URL**: https://www.nav.no/lese-skrive-vansker
- **Hjelpemidler**: Lese- og skrivehjelpemidler

### Ortopedi og proteser
- **URL**: https://www.nav.no/protese-ortose-ortopediskesko-parykk
- **Hjelpemidler**: Proteser, ortoser, ortopediske sko, parykker

---

## Bestilling og tilgang

### Bestillingsordningen
- **URL**: https://www.nav.no/bestillingsordningen
- **Formål**: Forenklet bestilling av standard hjelpemidler

### Brukerpass
- **URL**: https://www.nav.no/brukerpass
- **Formål**: For erfarne hjelpemiddelbrukere

### Søknad om hjelpemidler
- **URL**: https://www.nav.no/soknader
- **Formål**: Digitale søknadsskjemaer

### Arbeidsgivers hjelpemiddelsentral
- **URL**: https://www.nav.no/arbeidsgiver/hjelpemiddelsentral
- **Formål**: Arbeidshjelpemidler for varig funksjonshemming (>2 år, nødvendig for jobb)

### Funksjonsassistanse
- **URL**: https://www.nav.no/funksjonsassistanse
- **Formål**: Lese-, sekretær- og mentorhjelp

---

## Tilrettelegging

### Tilrettelegging på jobb og utdanning
- **URL**: https://www.nav.no/tilrettelegging-jobb
- **Formål**: Tilretteleggingstiltak på arbeidsplassen og i utdanning

### Tilrettelegging barnehage og skole
- **URL**: https://www.nav.no/tilrettelegge-barnehage-skole
- **Formål**: Tilrettelegging i barnehage og skolemiljø

### Tilrettelegging av bolig
- **URL**: https://www.nav.no/tilrettelegge-bolig
- **Formål**: Tilpasning av bolig via kommunal ergoterapeut/fysioterapeut + NAV hjelpemiddelsentral
- **Samarbeid**: Husbanken/kommune kan delta

### Førerhund
- **URL**: https://www.nav.no/forerhund

### Servicehund
- **URL**: https://www.nav.no/servicehund

### Tolking
- **URL**: https://www.nav.no/tolketjenester
- **Alternativ**: https://www.nav.no/trenger-tolk
- **Formål**: Tolking for tale, tegnspråk, døvblinde
