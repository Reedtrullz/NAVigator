# 13 - Tjenester etter målgruppe

NAV og tilhørende tjenester er organisert etter ulike målgrupper.

---

## Ungdom under 30

### Ungdomsgarantien
- **URL**: https://www.nav.no/ungdomsgarantien
- **Målgruppe**: 16–under 30 som trenger NAV-hjelp
- **Innhold**: Fast kontaktperson, CV/jobsøking, arbeidstrening, utdanning, arbeidstilpasning, samordning
- **Under 18**: Trenger samtykke fra foresatte

### Ungdomsprogrammet
- **URL**: https://www.nav.no/ungdomsprogrammet
- **Målgruppe**: 18–30, hel program
- **Pilot**: Agder, Vestland, Vestfold-Telemark
- **Innhold**: Arbeidstrening, utdanning, oppfølging

### Samtykke fra foresatte (under 18)
- **URL**: https://www.nav.no/samtykke-foresatte

---

## Innvandrere og flyktninger

### Introduksjonsprogram og stønad
- **URL**: https://www.nyinorge.no/introduksjonsprogram/
- **Ansvar**: Kommunal oppgave (NAV kan samordne)
- **Innhold**: Norskkurs, samfunnskunnskap, arbeidsmarkedstiltak

### Arbeidsrettet oppfølging
- **URL**: https://www.nav.no/arbeidsrettet-oppfolging
- **Formål**: Sysselsettingsrettet oppfølging for innvandrere

### NAV Ukraina
- **URL**: https://www.nav.no/ukraina
- **Formål**: Kollektiv vernede kan arbeide direkte eller tilbys introduksjonsprogram

## Personer med psykisk helse og/eller rus

### IPS (Individuell plassering og støtte)
- **URL**: https://www.nav.no/ips
- **Målgruppe**: Moderat/alvorlig psykisk lidelse og/eller rusproblemer

### IPS Ung
- **URL**: https://www.nav.no/ips-ung
- **Målgruppe**: 16–30 i behandling

### Arbeidsrettet rehabilitering
- **URL**: https://www.nav.no/arbeidsrettet-rehabilitering
- **Målgruppe**: Nedsatt arbeidsevne pga. sykdom/handikap/sosiale problemer

### Jobbmestrende oppfølging
- **URL**: https://www.nav.no/jobbmestrende-oppfolging
- **Målgruppe**: Alvorlige psykiske helseproblemer

### Grønt arbeid
- **URL**: https://www.nav.no/gront-arbeid
- **Målgruppe**: Psykisk helse/rus-utfordringer

### Senter for jobbmestring
- **URL**: https://www.nav.no/senter-for-jobbmestring
- **Målgruppe**: Angst og depresjon

### NAV Arbeidsrådgivning
- **URL**: https://www.nav.no/arbeidsradgivning
- **Målgruppe**: Psykisk helse som påvirker arbeidsevnen

### Arbeidsrettet veiledningstjeneste (kognitive utfordringer)
- **URL**: https://www.nav.no/arbeidsrettet-veiledningstjeneste
- **Målgruppe**: Hukommelse, tid, struktur, planlegging

### Psykiske helseproblemer
- **URL**: https://www.nav.no/psykiske-helseproblemer

### Rus - kontakt kommunal rustjeneste
- **Inngang**: Lokal NAV/rustjeneste
- **Innhold**: Ruskonsulent, henvisning, spesialisthelse, midlertidig opphold, bolig

### Midlertidig botilbud
- **URL**: https://www.nav.no/midlertidig-botilbud

### Hjelp til bolig
