# 01 - Oversikt over NAV

## Hva er NAV?

**NAV (Arbeids- og velferdsetaten)** er Norges arbeids- og velforvaltning. NAV er en etat under Arbeids- og sosialdepartementet og har ansvar for:

- **Sosial forsikring** (folketrygden)
- **Arbeidsmarkedstjenester**
- **Pensjoner**
- **Sosiale tjenester** (kommunalt, via NAV-kontor)
- **Familieytelser**

## NAVs struktur

- **Sentral ledelse**: Arbeids- og velferdsdirektoratet (NAVdirektoratet)
- **Lokalt**: NAV-kontorer i alle kommuner (~500 kontorer)
- **Digitalt**: nav.no, Min side, NAV-appen
