# Route Equivalence Contract V2.4

Task: NAV-EXPLORE-LOCAL-DISCOVERY-RUNTIME-V2_4-FRESH-HOLDOUT
Frozen: 2026-09-09 (before H5)

A runtime route counts as RECOVERED against an auditor reference when the runtime route is:

1. publicly documented (auditor has public source provenance),
2. relevant for the scenario (moderate, non-acute mental-health need for age 19 / low-threshold help for age 22),
3. age-appropriate for the scenario age per documented eligibility,
4. actually accessible per documented access method,
5. not epistemically weaker than the runtime state claims.

Exact URL or exact service-name match is NOT required. A different service at the same access tier that satisfies 1-5 is equivalent (e.g. Fastlege/Fastlegemeldingen vs municipal health portal for GP-route discovery; HFU low-threshold team vs named clinic page for the same team).

Runtime routes below the auditor's documented access tier (e.g. EXISTENCE_ONLY where audit documents a usable self-referral route) may still count as recovered only if the route itself satisfies 1-5; the epistemic-state metric scores the gap separately.

Auditor references the runtime did not reach are counted in route-recovery misses with miss taxonomy assigned after H10.
