# 04 - Helsetjenester og tilbake til arbeid

NAV tilbyr tjenester for personer med helseutfordringer som påvirker arbeidsevnen.

---

## Arbeidsrettet rehabilitering
- **URL**: https://www.nav.no/arbeidsrettet-rehabilitering
- **Formål**: For personer med nedsatt arbeidsevne på grunn av sykdom, handikap eller sosiale problemer
- **Innhold**: Veiledning, motiv mestring, trening, arbeidsprøve, livsstilsendring
- **Hvem**: NAV vurderer og henviser

## IPS - Individuell plassering og støtte
- **URL**: https://www.nav.no/ips
- **Formål**: For personer med moderat/alvorlig psykisk lidelse og/eller rusproblemer som ønsker betalt arbeid
- **Samarbeid**: NAV + helsevesenet jobbspesialist
- **Varighet**: Oppfølging så lenge det er behov
- **Henvisning**: Lokal henvisning via NAV/helse

## IPS Ung
- **URL**: https://www.nav.no/ips-ung
- **Formål**: For 16–30 åringer i behandling for psykisk helse/rus som ønsker arbeid/utdanning
- **Funksjon**: Tilpasset karrierestøtte med integrert jobbspesialist

## Jobbmestrende oppfølging
- **URL**: https://www.nav.no/jobbmestrende-oppfolging
- **Formål**: Arbeidstrening og oppfølging for alvorlige psykiske helseproblemer

## Grønt arbeid
- **URL**: https://www.nav.no/gront-arbeid
- **Formål**: Gårdsarbeid for psykisk helse/rus-utfordringer

## Senter for jobbmestring
- **URL**: https://www.nav.no/senter-for-jobbmestring
- **Formål**: For angst og depresjon - komme inn i/beholde jobb

## Arbeid og psykisk helse (for arbeidsgivere)
- **URL**: https://www.nav.no/samarbeidspartner/arbeid-og-psykisk-helse
- **Formål**: Informasjon til arbeidsgivere om psykisk helse og arbeid

## Reisetilskudd
- **URL**: https://www.nav.no/reisetilskudd
- **Formål**: Reisekostnadstilskudd som gjør det mulig å arbeide (kan kombineres med graderte sykepenger)

## Ekspertbistand (for arbeidsgivere)
- **URL**: https://www.nav.no/ekspertbistand
- **Formål**: Tilskudd til arbeidsgiver for ekspert bistand ved sykefravær/arbeidsmiljø
