# 05 - Tiltak og inkludering

NAV tilbyr en rekke arbeidsmarkedstiltak og inkluderingstilskudd.

---

## Arbeidsmarkedstiltak

### Tiltakspenger
- **URL**: https://www.nav.no/tiltakspenger
- **Formål**:godtgjøring under godkjent arbeidsmarkedstiltak
- **Hvem**: Registrerte jobbsøkere med NAV-vedtak

### Tilleggsstønader
- **URL**: https://www.nav.no/tilleggsstonader
- **Formål**: Refusjon av ekstrautgifter under tiltak (reise, barnepass, flytting, skole)

### Arbeidstrening
- **URL**: https://www.nav.no/arbeidstrening
- **Formål**: Arbeidserfaring med tilpassede oppgaver

### Arbeid med støtte
- **URL**: https://www.nav.no/arbeid-med-stotte
- **Formål**: Oppfølging i ordinært arbeid

### Varig tilrettelagt arbeid (VTA)
- **URL**: https://www.nav.no/varig-tilrettelagt-arbeid
- **Formål**: Skjermet/ordinær bedrift, tilpassede oppgaver
- **Hvem**: Generelt uføretrygdede

---

## Inkluderingstilskudd til arbeidsgivere

### Midlertidig lønnstilskudd
- **URL**: https://www.nav.no/midlertidig-lonnstilskudd
- **Formål**: Øke sjansen for ordinær lønnet jobb

### Varig lønnstilskudd
- **URL**: https://www.nav.no/varig-lonnstilskudd
- **Formål**: For varig vesentlig nedsatt arbeidsevne

### Inkluderingstilskudd
- **URL**: https://www.nav.no/inkluderingstilskudd
- **Formål**: Dekke dokumenterte ekstra tilpasningskostnader på arbeidsplassen

### Ekspertbistand
- **URL**: https://www.nav.no/ekspertbistand
- **Formål**: Ekspert bistand for arbeidsgiver+ansatt ved fravær/arbeidsmiljø

### Rekrutteringsprogrammet
- **URL**: https://www.nav.no/rekrutteringsprogrammet
- **Formål**: Rekruttering innen helse/omsorg

### Tilskudd sommerjobb
- **URL**: https://www.nav.no/tilskudd-sommerjobb
- **Formål**: Subsidere sommerjobber for ungdom

---

## Opplæring og mentoring

### Opplæring
- **URL**: https://www.nav.no/opplaring
- **Formål**: Kvalifisering til jobb, inkl. grunnopplæring, fagutdanning, høyere utdanning

### Mentor
- **URL**: https://www.nav.no/mentor
- **Formål**: Praktisk veiledning/opplæring for å mestre arbeid/utdanning

### Studier med støtte
- **URL**: https://www.nav.no/studier-med-stotte
- **Formål**: For psykisk helseproblemer som trenger hjelp til å fullføre skole/studier

---

## Oversikter

### Tiltaksarket
- **URL**: https://www.nav.no/tiltak
- **Formål**: Oversikt over alle arbeidsmarkedstiltak NAV tilbyr
