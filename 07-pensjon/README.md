# 07 - Pensjon

NAV forvalter alderspensjon, AFP og enkelte overgangsordninger.

---

## Alderspensjon
- **URL**: https://www.nav.no/alderspensjon
- **Formål**: Pensjon fra folketrygden, kan tas ut fra 62 år
- **Minimum**: 5 års medlemskap, fullt minimum etter 40 år
- **Gradert**: Kan tas ut i grader fra 62 år
- **Kombinasjon**: Kan kombineres med arbeidsinntekt uten reduksjon
- **Søknad**: Via "Din pensjon" (normalt 4 måneder før ønsket utbetaling)

## AFP privat sektor
- **URL**: https://www.nav.no/afp-i-privat-sektor
- **Formål**: Livsvarig tariffbasert pensjonsordning
- **Hvem**: Ansatte i AFP-bedrifter, Fellesordningen avgjør vilkår
- **Søknad**: Til pensjonsleverandør/Fellesordningen

## AFP offentlig
- **URL**: https://www.nav.no/afp-offentlig
- **Formål**: Tidligpensjon 62–67 for offentlig ansatte med tjenestevilkår
- **Fast tillegg**: ~1 700 kr/mnd ved full AFP

## Supplerende stønad (kort botid)
- **URL**: https://www.nav.no/supplerende-stonad-for-personer-med-kort-botid-i-norge
- **Formål**: Lavpensjon for 67+ med kort botid i Norge

## Pensjonsopptjening ved omsorg for barn
- **URL**: https://www.nav.no/omsorgsopptjening-barn
- **Formål**: Pensjonsopptjening (ikke kontanter) for omsorg for barn under 6, eller sykt/handikappet 6–18

---

## Selvbetjening og verktøy

### Din pensjon
- **URL**: https://www.nav.no/pensjon/selvbetjening/dinpensjon
- **Formål**: Logg inn for å beregne, søke/endre pensjon

### Pensjonskalkulator
- **URL**: https://www.nav.no/pensjon/kalkulator/login
- **Formål**: Beregne fremtidig alderspensjon, AFP og tjenestepensjon

### Pensjon - generell veiledning
- **URL**: https://www.nav.no/pensjon

### Søke pensjon fra utlandet
- **URL**: https://www.nav.no/soke-pensjon-fra-utlandet
